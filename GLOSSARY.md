# polotto.dev

Blog pessoal em pt-BR com textos longos e autorais para devs plenos,
sêniores e tech leads de mobile e back-end.

## Termos

**Artigo**:
Texto autoral publicado no blog, escrito no vault.
_Evitar_: post, postagem, nota

**Série**:
Sequência ordenada de artigos sobre um mesmo tema, com página própria de
índice. Exemplo: Migrando o legado.
_Evitar_: trilha, coleção

**Vault**:
O Obsidian em `~/Documents/Polotto`, fonte de verdade dos artigos.
_Evitar_: notas, Obsidian (como lugar)

**Sincronizar**:
Copiar do vault para o repo os artigos prontos para publicar, convertendo
o que é próprio do Obsidian.
_Evitar_: exportar, importar, deploy

**Projeto**:
Algo que o Angelo construiu e mostra no site, com nome, descrição, status e
links. Estudo, fork e repo de trabalho não são projeto.
_Evitar_: repo, portfólio, app (para o item da lista)

**Linguagem de design**:
Base visual comum a todos os projetos pessoais: escalas, espaçamento,
componentes e regras. Iniciativa própria; o blog é o primeiro consumidor.
_Evitar_: DS, design system (para a base comum)

**Tema**:
Camada visual de um projeto sobre a linguagem de design. O blog usa o tema
retrô gaming 16-bit; o Live Player, o tema Console.
_Evitar_: skin, marca (para a camada visual)

**Modo**:
Variação clara ou escura de um tema, escolhida pelo sistema do leitor.
_Evitar_: tema claro, tema escuro, dark theme

## Ambiguidades resolvidas

- "Status" é só a publicação no site (`rascunho` ou `publicado`). A fase de
  um projeto (ativo, pausado, encerrado) é **situação**.

- "Retrô gaming" é a estética 16-bit (SNES, Mega Drive). Não é 8-bit, nem
  Game Boy, nem terminal CRT.
